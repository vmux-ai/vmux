# Arrange your workspace

Vmux lets you keep several pages visible together. A Space holds your working context, a Tab keeps an arrangement, and a Pane is an area that displays a page.

## Start with one page

Open a website as you would in Chrome. When you want an assistant or another source beside it, split the workspace and open that page in another Pane. Resize the boundary so both remain readable.

For a flight comparison, keep two offers beside the Session. For a code change, keep Browser, Code, and the Session visible, with Terminal where you can follow the server or tests. For cooking, keep the recipe beside the chosen step order.

## Use tabs for different arrangements

Keep related pages in one Tab's arrangement. Use another Tab when you want a different set of pages without replacing the first.

Each Pane keeps its own page history. Back and Forward in one Pane do not replace the pages in its neighbors.

## Know what has focus

Click the Pane you want to use before typing or navigating. Keyboard and navigation commands act on the focused page.

A pending multi-key shortcut is canceled when you switch window focus or change its bindings. Start the shortcut again in the new context. Text fields keep leader keys that are not claimed by a direct shortcut.

An agent's ongoing task keeps its own Session and working folder when you focus another page. You can inspect another source without redirecting the background work.

## Keep quick access and collections

Pins remain top-level quick-access icons. Bookmark folders organize saved pages into collections, and can be expanded or collapsed. Use [Bookmarks](bookmarks.md) to keep trip, shopping, recipe, and work references organized.

## Switch tasks with Spaces

Use another Space for a different working context and return to the first when needed. Its Project/profile context stays associated with the work. Another window can show the same Space name while keeping its own local panes, tabs, and focus.

Moving or hiding a page does not necessarily stop its conversation or process. Use the Session or Terminal controls when you want the work to end.
