# Browser

Browse as you would in Chrome: type a URL or search in the address bar, open links, reload, and move through page history with Back and Forward.

## Keep useful pages open

Use tabs to return to a set of pages. Split the workspace when you want a source beside a Session, two product offers beside each other, or a running app beside its code. Each pane keeps its own page history.

Save pages you want to revisit as bookmarks. Use folders for a trip, purchase, or recipe collection; see [Bookmarks](bookmarks.md).

## Research with an agent

Open the relevant site and describe the task in a Session. Browser tools let a connected agent open sites, read what is on the page, and scroll while you follow its work.

Ask for sources and open the important offers or instructions yourself. For a flight or purchase, check the current seller page and final details before completing checkout. For a recipe, keep the source and your chosen steps visible together.

## Keep what you learned

Ask the agent to save a useful comparison or summary in [Knowledge](knowledge.md). A bookmark returns to the source; the note keeps the requirements, decisions, and changes you want to reuse.

Websites remain ordinary web content. Vmux's own pages, such as Code, Terminal, and Sessions, are tools in the same workspace.
