# Bookmarks

Bookmarks keep websites and Vmux pages you want to return to. Pins provide quick access; bookmark folders organize a larger collection.

## Organize around a purpose

Use a folder for a trip, purchase, or recipe collection. Add subfolders when the collection needs them, for example:

- Trips → Lisbon → Flights and Hotels.
- Shopping → Home → Product comparisons and Support.
- Recipes → Weeknight dinners and Favorites.
- Work → a project → its running app, PR, and documentation.

Use the bookmark and folder menus to save a page, create a folder, and move items into the right place. Folder choices show the nested path so you can distinguish similarly named groups.

## Keep a source and a note

Bookmark the airline offer, product page, recipe, or PR. Use [Knowledge](knowledge.md) for your own comparison, preferences, receipt details, or recipe changes. Both are useful when a later Session continues the work.

## Ask an agent to help

An agent can list bookmarks, create folders, save pages into a chosen folder, and pin frequently used pages. Tell it which collection you want to organize and which links belong there.
