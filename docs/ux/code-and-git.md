# Code and Git

Code is Vmux's built-in file editor. Git lets you inspect a repository's changes, make checkpoints, and share a branch for review.

## Open the files for the task

Select the Project and its folder, then open Code. Browse the file tree or search for a filename or text. An agent's Editor tools can read and show the relevant files beside the conversation.

For a web app, keep its page open in Browser while editing. Use Terminal for the project's development server and tests. A preview of another folder stays read-only until you activate it for the work.

## Review what changed

Open Git to see changed files and their diffs. A commit is a checkpoint in the repository; a branch keeps a change separate while you work on it. For an agent task, review the diff and try the result before asking it to commit and push.

A PR shares that branch for review. It can live in your own fork or the repository you contribute to. Open its link in Browser and return to the Session when feedback needs another change.

Follow [Fix a bug and make a PR](make-a-pr.md) for the complete example. To develop Vmux itself, use [Getting started](../dx/getting-started.md).
