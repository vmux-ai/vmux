# Find and book a flight

Imagine a weekend trip from Paris to Lisbon. You want a flight within your budget, sensible travel times, and a booking you can find again later.

## 1. Start with the trip

Open a flight-search website in Browser. Start a Session and give the agent your exact dates, airports, passenger count, baggage needs, and budget. For example:

> Find Paris–Lisbon flights for my weekend trip. Leave Friday after 18:00, return Sunday evening, and include one cabin bag. My budget is €300. Show three options with the full price and booking links.

Replace the example's dates and conditions with your own. Ask the agent to read your travel-preferences note in Knowledge if you already have one.

For a larger trip, ask it to create or select a Project such as “Lisbon weekend.” It can suggest a folder if the Project needs one. Keep the flight Session there, and use another Session for accommodation. Both should use the same dates and budget.

## 2. Compare the actual offers

Keep the search results open beside the Session. The Browser tools let the agent open sites, read pages, and inspect the options you can see.

Ask for a comparison of departure/arrival times, airports, baggage, connections, cancellation terms, and the price at the seller. Open the shortlisted offers yourself and check that those conditions still apply. Save useful airline and booking pages in a trip bookmark folder.

## 3. Choose and prepare the booking

Tell the agent which option you want. Open its booking page and work through the passenger and baggage choices. Check the exact dates, passenger names, airports, and final total before payment.

If the agent is helping with the website, review the completed booking details before authorizing the purchase. You can also complete the checkout yourself in Browser.

## 4. Keep the confirmation

Wait for the booking confirmation and reference. Ask the agent to save the flight times, booking reference, and confirmation link in a Knowledge note for this trip. Review the note that opens beside the conversation.

Return to that note or Session when arranging the rest of the trip. Keep hotel research in its own Session, then ask for one itinerary using the confirmed flight and accommodation details.
