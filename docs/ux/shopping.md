# Buy something

Suppose you want a quiet robot vacuum for a small flat, with a €400 budget. Use Vmux to keep the requirements, product pages, and comparison together through checkout.

## 1. Tell the agent what matters

Open a shopping or review site in Browser and start a Session:

> Find three robot vacuums under €400 for a small flat. Prioritize low noise, easy maintenance, and availability here. Compare the total price, warranty, return policy, and replacement-part costs. Include links to the actual offers.

Add your country, delivery deadline, floor type, and any other important constraint. Ask the agent to read a shopping-preferences note in Knowledge if you have one.

For a larger purchase, keep the research in a Project with related Sessions. One Session can compare models while another checks retailer prices and delivery. Give both the same requirements.

## 2. Compare products and sellers

Keep product, review, and seller pages beside the conversation. Ask the agent to explain the tradeoffs using those sources. Check the shortlisted models on the seller's site; a review price or headline discount may differ from checkout.

Bookmark the finalists in a folder for this purchase. Ask for a Knowledge note with the requirements, comparison, and links so another Session can continue the research later.

## 3. Review the purchase

Choose the model and seller. Open the offer, check the exact variant, delivery address, shipping cost, return conditions, and final total. Review any checkout the agent prepares before authorizing payment, or complete it yourself in Browser.

## 4. Save what you will need later

After confirmation, keep the order reference, receipt link, warranty information, and support page with the purchase note. Return to the Session if you need to compare an accessory, arrange a return, or find maintenance instructions.
