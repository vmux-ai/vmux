# Knowledge

Knowledge keeps notes you and an agent can find again: travel preferences, product comparisons, recipes, project decisions, or meeting notes.

## Save a useful result

After reviewing a result, ask the agent to save it. For example:

> Save this flight comparison and my baggage requirements in Knowledge under Lisbon weekend. Include the booking links.

The Knowledge tool writes a Markdown note and opens it beside the conversation. Read it, correct missing details, and keep the sources you want to return to.

## Reuse it in another Session

Tell the next agent what to look for:

> Read my Lisbon weekend note and use the confirmed flight times to plan the itinerary.

Agents can search Knowledge, read a matching note, and use its contents in the task. You can also browse and edit notes through the Knowledge page. Link related notes when a trip, purchase, recipe, or project needs several pages.

## Keep the right things

Bookmarks bring you back to websites. Knowledge stores your own summary, preferences, decisions, and changes. For a recipe, keep both the source bookmark and a note with the portions and substitutions that worked for you.
